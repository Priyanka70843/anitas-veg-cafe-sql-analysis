# Anita's Veg Café — SQL Data Analysis

## 📌 Project Overview

This project analyzes customer orders and loyalty-program data for Anita's Veg Café using SQL.

The analysis focuses on customer spending, ordering behavior, popular dishes, loyalty membership activity, and reward points.

## 🛠️ Tools & Technologies

* SQL
* PostgreSQL
* GitHub

## 📊 Analysis Performed

The project answers 10 business questions, including:

1. Total amount spent by each customer
2. Number of distinct days each customer placed an order
3. First dish ordered by each customer
4. Most popular menu item overall
5. Most frequently ordered dish by each customer
6. First dish ordered after joining the loyalty program
7. Last dish ordered before joining
8. Items and amount spent before joining
9. Loyalty points earned by each customer
10. Loyalty points earned during the first loyalty week

## 💡 Key SQL Concepts Used

* `SELECT`
* `JOIN`
* `GROUP BY`
* `ORDER BY`
* `CASE`
* Aggregate functions such as `SUM()` and `COUNT()`
* `DISTINCT`
* Subqueries
* Window functions
* `RANK()`
* `ROW_NUMBER()`
* Date filtering and date calculations

## 🎯 Project Objective

The objective of this project is to practice SQL data analysis by transforming raw café transaction data into meaningful business insights related to customer behavior and loyalty programs.
